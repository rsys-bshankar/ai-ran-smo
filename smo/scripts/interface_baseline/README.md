# Interface gate baseline (`scripts/check_interfaces.py`)

Written by `python scripts/check_interfaces.py --write-baseline`, one file per module (`scripts/baseline_dirs.py`); entries may only be removed (plan task S0.17). producer: served routes neither in the bundle nor a listed [D] exception, with their ADR 0011 appendix A fate and the PR-CONV row that removes them. consumer: calls of the SMO's own code that reach only such routes.

A producer entry belongs to the module that serves the route; a consumer entry to the module whose file makes the call. In CI the gate also fails when an entry is added against the pull request's base (`--base-ref`), per entry and so per module.
